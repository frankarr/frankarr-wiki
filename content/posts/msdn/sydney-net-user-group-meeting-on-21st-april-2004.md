Sydney .NET User Group Meeting on 21st April, 2004 The next Sydney .NET User Group Meeting is on this week. The folks are talking about combining Exchange Data, SQL Data and SQL Reporting Services. Come see a code packed session that will show how to extend the out-of-the box features of Reporting Services. Everyone who has an Exchange Server 2000/2003 should be reporting on it but nobody does. Following this, they will explore the creation of a real Reporting Services solution. You will learn about the important issues of security, data access, rendering, and delivery. They will also discuss the deployment issues of an application that requires Reporting Services. Sample code is provided so you can use this useful solution. In addition, following on in the theme of the previous day's Mobile Developer Conference, Dr. Neil is going to present a couple of things that didnt make it into this years MDC . This will include some Smartphone with location and mapping services. Wednesday 21th April. 6:00 pm at Microsoft, 1 Epping Road North Ryde Additional resources Last updated on 2004-04-19
