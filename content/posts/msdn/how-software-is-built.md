How Software is Built Saw an email fly by this morning about the site www.howsoftwareisbuilt.com I went over to have a look and this is what I found A blog forum to provide deep dive analysis and community conversations about software development models. The interviews are pretty detailed and have a lot of golden nuggets. Some of the people interviewed include: Britten Martin David Campbell Shawn Burke Blaine Wastell and Glenn Block Steve Morris Doug Look Michael Tiemann Bob Bray Matt Gibbs Rod Johnson Josh Berkus John McCreesh James Reinders-Video Ryan Waite Jay Pipes Patrick Hogan Marc Miller Phil Costa Michael Howard Stormy Peters Shawn Burke Mark Gross IMHO, any blog with a set of Ground rules for facilitating analysis and community conversations about software development models must make for an interesting set of conversations.
