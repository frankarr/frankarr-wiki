Announcing Visual Studio integration in new version of Ruby.NET Got the latest news from the team working on the Gardens Point Ruby.NET compiler From: Wayne Kelly Sent: Tuesday, 8 May 2007 11:30 AM To: Frank Arrigo Subject: Announcing Visual Studio integration in new version of Ruby.NET Dear frank arrigo, We are pleased to announce the release of a new Beta (version 0.7) of the Gardens Point Ruby.NET compiler. Since our last release we integrated Ruby.NET into Visual Studio, allowing users to edit, build, execute and debug Ruby programs within Visual Studio 2005. This includes break points, syntax colouring, error highlighting, brace matching, hidden regions, Ruby.NET projects, project properties, project templates and project item templates. Ruby.NET projects (.rbproj) enable multiple Ruby source files to be compiled into a single .NET assembly. We have also extended and fixed bugs in the compiler and our implementation of Ruby's standard classes and modules. See our home page for full source downloads and further details ( https://plas.fit.qut.edu.au/Ruby.NET ). Cheers, Wayne.
