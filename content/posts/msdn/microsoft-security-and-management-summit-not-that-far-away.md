The next
Microsoft Security and Management Summit
is coming soon
in June 2004. This complimentary, full day technical briefing will build on

Register Now
To register, or for more information, please visit:

Event Overview
This invaluable event will consist of two key streams:
Security
Our latest series of talks are designed to address
more advanced security topics and preview a number of important security
technologies including:
Windows XP Service Pack 2
Windows Server 2003 Service Pack 1
Internet Security and Acceleration Server 2004
Attend specific sessions on:
Server and client security.
Application and data security.
Applied security strategies.
A number of resources will be distributed and highlighted at the event.
For more information visit the
Microsoft
Security Tools & Resources
page.
For a refresher of the March Summit,
click
here to view an overview of the presentations and see a video of the keynote
speech.
Management
The management stream will provide an overview of
the latest enhancements in Microsoft management technologies. You will
receive:
An overview of the recently announced Microsoft Operations Manager
2005 and Systems Management Server 2003.
A briefing on the System Centre roadmap.
A demonstration of how you can extend Microsoft management tools
into operating systems such as Unix and Sun, and provide deep analysis tools
utilising our premier management partner NetIQ.
This is a must-attend event for any IT professional concerned about the
security and management of their IT infrastructure.
