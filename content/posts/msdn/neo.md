NEO When the news that objectspaces would be 'delayed' hit, a number of folks started to grizzle. No need. Have a look at NEO , otherwise know as The .NET Entity Objects Framework Neo is a framework that provides an object facade for ADO.NET to the application developer. It includes tools to create the database schema from the object model and provides rich schema information at runtime allowing it to dynamically generate all SQL required for object persistence management. At the same time, much like ADO.NET DataSets, it is independent of the actual backing store and works equally well with objects transmitted in an XML representation.
