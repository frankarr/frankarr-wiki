Smart Client Offline Application Block - As mentioned in the Security Summit session During one of the sessions at the Security Summit , both Charles Sterling & Andrew Coates mentioned the Smart Client Offline Application Block . Well, it is now live on MSDN. This block has re-usable code and samples which show how you can build smart client applications which can operate offline. With this block your application can detect the presence or absence of a network connection, cache data for use while offline, and re-synchronize data and tasks with the network once the application goes online. The block uses a store and forward mechanism which is suitable for message-based interactions with the network, such as you would get with a smart client operating in a service oriented environment.
