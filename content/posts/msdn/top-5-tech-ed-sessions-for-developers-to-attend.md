Top 5 Tech.Ed Sessions for Developers to Attend
I was asked to give my top 5 sessions to attend at this
Tech.Ed 2005
, for inclusion in the
upcoming MSDN Flash
.
You know, it's hard to give the top 5 sessions, since they are all so good, so what I have tried to do is pick a sampler of the 5 sessions that I would go to, as well as the reason why I picked them. Check out the Tech.Ed Web site for
more details on these and other sessions
.
Microsoft's Security Development Lifecycle
We all need to know more about developing secure code
ASP.NET 2.0: Best Practices for Building Web Application User Interfaces
It' s all about the web baby!
Indigo Architecture Overview
How can we start taking advantage of the features of Windows Vista.
What's New in Visual Basic .NET 2005
I always want to know what' s new, now I can find out.
Visual Studio 2005 Team System: Managing the Software Lifecycle with Visual Studio 2005 Team System
Since we all work together in teams, we need to know how to get along.
