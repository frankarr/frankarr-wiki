Windows XP Service Pack 2: Webcast Overview for ISVs This is worth attending. even if the time is a bit nasty for the folks downunder. Tony is an Aussie. He is a great speaker. You are invited to attend an informational webcast for Independent Software Vendors on Friday, April 23rd at 12:00 (PST) to learn about the important security changes in the Windows XP Service Pack 2. In this one hour overview, you will learn about the new Windows firewall, security for email & IM, enhanced web browsing, and system level protection improvements. Come to this interactive webcast and hear Tony Goodhew, Microsoft Product Manager explain the importance of this Service Pack and how it may affect Independent Software Vendors.
