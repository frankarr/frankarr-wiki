Windows XP Media Center Edition
Powered by Microsoft Windows XP Media Center Edition, Media Center PCs are complete Windows XP PCs enhanced for home entertainment. These computers represent the evolution of home PCs into digital media hubs that bring together your entertainment choices and allow you to access them with one remote control.
The Media Center platform enables developers to create rich media applications and services, including remote-controlled HTML applications, hosted .NET add-ins, front panel display components, and more.
This section contains programmability documentation, sample programs and templates, Media Center UI guidelines, and other resources for software development on the Media Center platform.
