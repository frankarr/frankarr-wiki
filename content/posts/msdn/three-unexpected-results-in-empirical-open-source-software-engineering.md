Unexpected result 2: Linux is unmaintainable Common coupling = shared global variables = bad software engineering.  It leads to unmaintanable code because the coupling introduces dependencies of otherwise unrelated modules. Results: The number of instances of common coupling grows exponentially with version number The number of lines of code grows linearly with version number Conclusion: As Linux grows in size, it will become unmaintainable Linux was found to have > 10 times the couplings (and all of them are bad, just that some are much worse than others) than OpenBSD, FreeBSD and NetBSD.
