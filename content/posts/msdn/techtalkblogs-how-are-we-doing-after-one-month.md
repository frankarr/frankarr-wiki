What Makes A Good Data Entry App Techtalkblogs.com Now, someone asked me how the ranking system worked. It's pretty simple. A post gets a set of points at the start (Let's call this I), then points are added per vote (let's call this V) and finally points are deducted each hour from initial posting (let call this H). The formula looks something like this : Rank Score = (I + NumberOf Votes * V) - (HourSincePost * H). The list is then sorted by this Rank Score I have been playing with the different values of the weekend, tweaking the values to see how the order of the stories change.
