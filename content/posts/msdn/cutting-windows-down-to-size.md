Cutting Windows down to size How creative..... A Melbourne-based software outfit has come up with a tool for getting rid of the bloat on Windows systems and literally cutting one's system down to size. Litepc has developed software which it markets as XPLite and 2000lite, which users can use to remove practically any component of Windows.
