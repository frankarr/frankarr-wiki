Windows Vista: Windows Presentation Foundation hands on lab Community activity around WPF: Dimension Data Learning Solutions and Microsoft would like to cordially invite you to the Windows Presentation Foundation (WPF) Day presented by Joseph Cooney and Deepak Kapoor. The Microsoft Windows Presentation Foundation (formerly code named "Avalon") provides the foundation for high fidelity application experiences in Windows; blending together application user interface, documents and media content, while exploiting the full power of your computer. This session will walk through the core concepts of WPF including Extensible Application Markup Language (XAML), data binding and application animation. This will be followed by a guided hands-on-lab session.
