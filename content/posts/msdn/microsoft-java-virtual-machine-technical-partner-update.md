Microsoft Java Virtual Machine Technical Partner Update Microsoft is committed to helping customers transition off the Microsoft Java Virtual Machine (MSJVM). To provide a smooth transition for current users of the MSJVM, Sun Microsystems and Microsoft have agreed to extend Microsoft's license to use Sun's Java source code and compatibility test suites. This extension allows Microsoft to support the MSJVM until 30 September 2004, and gives Microsoft the ability to address potential security issues. Register today for forthcoming technical workshops at www.microsoft.com/australia/events [event code: 159269] or visit www.microsoft.com/java for more information.
