BlogML and Single User Blog
Darren Neimke
is causing a minor revolution in the blogworld.
He came up with a spec a while back for BlogML
which provide a set of services around blog migration from one service to another. A very admirable concept.
Well the idea has legs. He's getting support from a number of the blogging engine developers out there, as he writes in his recent post titled
A big week for BlogML
and
he has set up a home for all the BlogML info
.
All it needs is a big service, like
MSN Spaces
(
Dare
are you reading this) or Blogger or WordPress or LiveJournal to endorse it and it will go off!
Speaking of blogging engines. Darren has also created one, which he calls
Single User Blog
, and which is up to
Version 2.0
. All the source code (nice ASP.NET v2) is on
Project Distributor
(another Neimke creation).
