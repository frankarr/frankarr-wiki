ASP.NET Hosting Technical Seminar Just wanted to let you know about the ASP.NET Hosting Technical Seminar we have running in April in Sydney, Melbourne & Brisbane. The event will be delivered by Matthew Boettcher, a technical marketing manager for the Microsoft Solution for Windows-based Hosting team.  Matthew has been working with internet and hosting service providers for the last five years and is based in Redmond. We are keen to see partners/customers who are specifically providing Web Hosting or Commercial services over the Internet today. By attending the April seminar attendees will be in the draw to WIN a cool Microsoft Windows Mobile – based Smartphone. The Seminar will provide information on the deployment, configuration, customization, testing and management of a shared hosting ASP.NET e-commerce application. Attendees will be presented with a review of the Windows Server 2003, IIS 6.0, SQL Server 2000 and ASP.NET technologies to configure a front-end Web server and back-end database server for Web-based e-commerce transactions using a customized version of the free ASP.NET Commerce Starter Kit that includes a small business administration console. Monday, April 19th - Sydney, Australia Wednesday, April 21st - Melbourne, Australia Friday, April 23rd - Brisbane, Australia Also at the event we will be discussing monthly subscription, Pay As You Go licensing for the hosted Microsoft technologies. Please go to https://www.microsoft.com/serviceproviders/webhosting/training/default.asp to register! Comments
