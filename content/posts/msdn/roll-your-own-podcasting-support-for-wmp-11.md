Roll your own podcasting support for WMP 11 So, the feeling is that Microsoft's lack of action will slow Podcasting Growth. James O'Neill has put together a step by step guide to subscribe to Podcasts under Windows Vista Not to be outdone, Dominic Cooney has cut some code in F# to create a rough and ready podcasting app for WMP 11. But, what about the podcast client for Windows Media Center that Charlie Owen demonstrated at Mix06 , aka " Q " ?? As Charlie says, "Q is not a shipping feature of Windows Vista -- it is a sample application for which source code will ship with the Windows Media Center Software Development Kit for Windows Vista."
