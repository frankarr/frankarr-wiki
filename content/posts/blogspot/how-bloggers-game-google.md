How bloggers game Google: "Google's new version 2.0 of their toolbar has a blog button. 'To use this feature you must set up a free account with Google's Blogger service. If you have an existing Blogger account already, you can use that as well. When you use BlogThis!, you create a blog post that points to the web page you're visiting. If you highlight text on the web page, that text will also appear in your blog post.' "
